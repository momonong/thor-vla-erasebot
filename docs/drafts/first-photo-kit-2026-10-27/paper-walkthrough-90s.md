| 預備問題 | 可支持的回答與仍缺證據 |

| 歧義拒絕是否就算成功？ | 不能代替唯一題成功。[P05-C01／C02](scoring-template.json)分別檢查歧義與 blue pear 唯一控制，需核對選中 ID 並保留正確／錯選／拒答分母；兩題人工答案與結果目前都缺 |

| 如何證明擦乾淨且保留鄰字？ | 需 M07 同次對齊前後影像與[研究稿量測定義](../../submission-plan.md)：目標殘留／原墨跡、非目標移除／原墨跡，不能只看 OCR 消失；原區域為零或不能對齊要不可評。M06／M07 原片、量測與介入紀錄均缺，見 F-ROBOT |
| 23 秒是擦拭耗時？已在 Thor 跑過？ | 都不是。[S03](shot-evidence-map.md)只有展示預算，[研究現況](../../submission-plan.md)沒有 Thor／ARM64／JetPack 執行證據。若未來實機超時須改分鏡，或明示節錄並附完整連續原片；實際平台與耗時證據仍缺 |
