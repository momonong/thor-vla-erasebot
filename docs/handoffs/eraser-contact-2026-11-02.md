# 板擦夾持與接觸施力：階段交接

## 使用者決策與承接範圍

2026-11-02，使用者決定先暫緩白板辨識最佳化，等待主辦明確定義後再調整；下一目標是機械手臂握住板擦及接觸白板時的施力。使用者要求另開對話、建議模型／推理深度，並先合併及推送既有辨識研究成果。本文件是這次階段交接，不是硬體已就緒或完成擦拭的宣告。

新對話建議題名「板擦夾持與接觸施力」。依既定模型分工，建議 Astra Ultra 負責需求、機構與控制方案、證據及最後核對，確認後的實作／除錯／測試交 Sol 6.1 Ultra。這是協作配置建議，不是本專案測得的模型能力排名，也不是機械手臂上的控制模型。

第一階段完成條件是硬體證據／未知項清單、夾持及接觸機構候選比較、可量測的小步測試計畫；先唯讀盤點、研究及討論。維持尚未連接／啟動手臂的現況，實機階段待設備條件與必要授權具備後再推進。不要恢復辨識資料擴充、微調、GPU／國網工作，也不要建立空殼控制模組。

這些影像／fixture 的座標都是影像位置，不是板面或機座座標；後續接回感知時需要獨立校正及擦具範圍驗證。

## 新階段先釐清的實體問題

1. **設備身份與控制能力：** 確認手臂、每種伺服、控制板、韌體、協定、線材、電源及組員曾使用的軟體。現有照片尚不足以確認品牌／型號與白黑兩套設備的角色；照片中的 5V／3A 電源須核對供應對象與規格，不能當成整臂電源已核准。
2. **夾持力：** 板擦如何被夾住，接觸面、重量與偏心會否導致滑動／旋轉；比較現有夾爪與專用轉接座，先有尺寸、質量及安裝證據。
3. **板面法向接觸力：** 板擦壓向白板的力如何量測與限制。夾緊板擦不代表壓板力已受控；USB-C／TTL 標示也不能證明有電流／力矩回授或真實力控。
4. **順應與姿態：** 比較彈性層、彈簧／浮動座、機械限位等候選，連同板面方向、固定方式、擦具厚度與可達範圍評估。這些是待比較選項，尚未選定或製作。
5. **量測與停止：** 寫清量測方法、滑移與接觸判準、停止方式、失聯行為及現場負責人；力、速度、行程限值須依規格及量測確定，不從照片猜值。

先交付機構／控制／量測方案，再依條件逐步安排「無接觸小動作 → 有量測的低速接觸 → 單次短距離擦拭」。每階段分別記錄夾持滑移、接觸力或其量測限制、停止反應、擦拭及保留區結果；未做過就標未驗證。初期可用人工指定區域隔離機械問題，不必先串接尚在研究的辨識輸出。
