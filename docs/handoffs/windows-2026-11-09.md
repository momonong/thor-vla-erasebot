# Windows 接續

本版為 0.3.0 襯材離線評分與批次報告。完整接續指示由 [Calcifer Windows 交接](https://github.com/momonong/calcifer/blob/main/docs/handoffs/windows-thor-2026-11-09.md) 維護；請依使用者提供的合併 SHA 固定兩個 repo 版本。

先讀 [研究與實驗方向](../liner-research-plan.md)、[評分契約](../liner-offline-evaluation.md)、[批次工具](../development/batch-report.md) 及 [版本驗證](../validation-0.3.0.md)。

Windows／PowerShell 可先使用原生 Python 3.12 測單筆評分：`py -3.12 -B -m unittest discover -s tests -p test_liner_evaluation.py -v`，以及 `py -3.12 -B -m liner_evaluation --target fixtures/liner-evaluation/target.json --observation fixtures/liner-evaluation/partial.json`（預期 exit 1）。批次工具依賴 POSIX fd／O_NOFOLLOW，原生 Windows 不支援；批次及全套測試改在 Linux 或待驗證 WSL。Linux 上通過不等於 Windows 已驗收。Calcifer 的隔離執行需另外確認 Linux／WSL 能力；不要為接手臂而在未知連線或未校正情況發送馬達指令。手臂接電後先做不發動作的環境盤點。
